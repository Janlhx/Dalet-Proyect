# Security Policy — Dalet

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported |
| :--- | :--- |
| `v4.0.x` (`main`) | Yes |
| `< v4.0` | No |

## Reporting a Vulnerability

If you discover a security vulnerability in **Dalet** (such as SSRF, authentication bypass, permission escalation, or secret exposure), **please do not open a public GitHub issue**.

Instead, report it privately via one of the following channels:
- **GitHub Security Advisories:** Use the *"Report a vulnerability"* button in the **Security** tab of this repository.
- **Direct Contact:** Reach out to **Litxe** in the official support server (*The Red Room of Dalet*) or via Discord `/feedback` for non-critical reports.

Please include:
1. A clear description of the vulnerability and its potential impact.
2. Steps or a minimal proof-of-concept to reproduce it.
3. Any suggested remediation if known.

We aim to acknowledge reports within **48 hours** and patch confirmed issues promptly.
